# GPU Bench

Misura le prestazioni della tua GPU NVIDIA con l'inferenza LLM (llama.cpp, vLLM): caricamento a freddo e a caldo, token/s, latenza, VRAM, consumi.

Sviluppo:

```
npm install
npm run build
npm start          # apre l'app Electron
npm run validate   # lint, typecheck, test, copertura 100%
```
